AI Coach: Perfect security awareness. Let's move to Topic 3: Sessions and Flash Messages. Can you explain what problem sessions solve and show me how you implemented flash messages?

---

Cristobal: sessions solve the problem that HTTP is stateless. each request is independent so the server doesn't remember previous requests from the same user. sessions create a temporary relationship between the browser and server using a session ID stored in a cookie. this lets me store data that persists across multiple requests.

flash messages use sessions to store temporary messages that survive a redirect but only display once. here's my flash middleware:

req.flash = function(type, message) {
    if (!req.session.flash) {
        req.session.flash = {
            success: [],
            error: [],
            warning: [],
            info: []
        };
    }

    if (type && message) {
        if (!req.session.flash[type]) {
            req.session.flash[type] = [];
        }
        req.session.flash[type].push(message);
        return;
    }

    if (type && !message) {
        const messages = req.session.flash[type] || [];
        req.session.flash[type] = [];
        return messages;
    }

    const allMessages = req.session.flash || {
        success: [],
        error: [],
        warning: [],
        info: []
    };

    req.session.flash = {
        success: [],
        error: [],
        warning: [],
        info: []
    };

    return allMessages;
};

AI Coach: Great question. Sessions are essential for any data that needs to persist across multiple requests for a specific user. The most common use case is authentication — storing whether a user is logged in and their user ID. You'll implement that in future weeks.

Other common uses include shopping carts in e-commerce sites, multi-step forms where you save progress between pages, user preferences like theme or language settings, and temporary data during workflows like password reset tokens.

The key principle is: if the data is user-specific and needs to survive page navigation or refreshes but isn't permanent enough for the database, sessions are the right tool. Flash messages are just one specialized use case of this pattern.
